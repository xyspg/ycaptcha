---
title: Embed the Widget
description: Add the yCAPTCHA widget to your webpage and listen for verification tokens.
---

The yCAPTCHA widget is delivered as an iframe that handles the entire challenge flow — from displaying the checkbox to showing the image grid and returning a verification token.

## Prerequisites

- A yCAPTCHA site with at least one [configured puzzle](/docs/get-started/create-site)
- Your Site Key (`pk_...`)

---

## 1. Add the iframe

Embed the widget wherever you want the CAPTCHA to appear:

```html
<iframe
  src="https://ycaptcha.xyspg.moe/widget/YOUR_SITE_KEY"
  id="ycaptcha-widget"
  style="border: none; width: 310px; height: 78px; overflow: hidden;"
  scrolling="no"
  title="yCAPTCHA"
></iframe>
```

Replace `YOUR_SITE_KEY` with your site's public key (`pk_...`).

---

## 2. Listen for events

The widget communicates with your page via `postMessage`. All messages have the shape:

```ts
{ source: "ycaptcha", event: string, ...payload }
```

### Receiving the token

When the user passes the challenge, the widget sends a `success` event with a one-time verification token:

```js
window.addEventListener("message", (event) => {
  if (event.data?.source !== "ycaptcha") return;

  if (event.data.event === "success") {
    const token = event.data.token;
    // Store the token to submit with your form
    document.getElementById("captcha-token").value = token;
  }
});
```

### All events

| Event     | Payload                      | Description                                          |
| --------- | ---------------------------- | ---------------------------------------------------- |
| `success` | `{ token: string }`         | User passed the CAPTCHA. Token is ready for verification. |
| `resize`  | `{ width, height: number }` | Widget wants its iframe resized.                     |
| `expired` | —                            | 5-minute session elapsed. Widget resets automatically. |
| `error`   | `{ code, message }`         | Fatal error (invalid siteKey, network failure, etc). |

---

## 3. Handle resize

The widget's dimensions change between states. It cannot resize its own iframe — you need to update it:

```js
const iframe = document.getElementById("ycaptcha-widget");

window.addEventListener("message", (event) => {
  if (event.data?.source !== "ycaptcha") return;
  if (event.data.event === "resize") {
    iframe.style.width  = event.data.width  + "px";
    iframe.style.height = event.data.height + "px";
  }
});
```

### Widget dimensions by state

| State                        | Approximate Size |
| ---------------------------- | ---------------- |
| Collapsed (idle, verified)   | 304 x 78 px      |
| Expanded (puzzle grid)       | 350 x 520 px     |

## Complete example

```html
<!DOCTYPE html>
<html>
<head>
  <title>yCAPTCHA Demo</title>
</head>
<body>
  <form action="/submit" method="POST">
    <input type="text" name="email" placeholder="Email" required />

    <iframe
      src="https://ycaptcha.xyspg.moe/widget/YOUR_SITE_KEY"
      id="ycaptcha-widget"
      style="border: none; width: 310px; height: 78px; overflow: hidden;"
      scrolling="no"
      title="yCAPTCHA"
    ></iframe>

    <input type="hidden" name="captcha-token" id="captcha-token" />
    <button type="submit">Submit</button>
  </form>

  <script>
    const iframe = document.getElementById("ycaptcha-widget");

    window.addEventListener("message", (event) => {
      if (event.data?.source !== "ycaptcha") return;

      switch (event.data.event) {
        case "success":
          document.getElementById("captcha-token").value = event.data.token;
          break;
        case "resize":
          iframe.style.width  = event.data.width  + "px";
          iframe.style.height = event.data.height + "px";
          break;
        case "expired":
          document.getElementById("captcha-token").value = "";
          break;
      }
    });
  </script>
</body>
</html>
```

---

## Widget phases

The widget progresses through these internal states:

| Phase       | Description                                          |
| ----------- | ---------------------------------------------------- |
| `idle`      | Collapsed checkbox, waiting for user click            |
| `loading`   | Spinner shown while fetching challenge               |
| `challenge` | 3x3 image grid displayed                             |
| `verified`  | Green checkmark, CAPTCHA passed                      |
| `error`     | Error message shown in collapsed bar                 |
| `failed`    | Internal only — automatically fetches a new challenge |

When verification fails, the widget does not show an error — it silently fetches a new challenge and lets the user try again.
