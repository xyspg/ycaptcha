Base URL:

```
https://ycaptcha.xyspg.moe
```

## Endpoints

| Endpoint | Purpose | Called by |
| --- | --- | --- |
| [`POST /api/v0/captcha/siteverify`](/docs/api-reference/siteverify) | Verify a CAPTCHA token server-side | **Your backend** |

The `/challenge`, `/verify`, and `/image` endpoints are internal to the widget and called automatically. You do not need to interact with them directly.

## Authentication

The **siteverify** endpoint requires your Secret Key (`sk_...`) and must only be called from your server. Never expose your Secret Key in client-side code.

## Rate limiting

Per-IP sliding window rate limits are enforced on all API routes:

| Route | Limit |
| --- | --- |
| `/siteverify` | 100 requests/min |
| Widget internal routes | 10–60 requests/min |
