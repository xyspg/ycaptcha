## What is yCAPTCHA?

yCAPTCHA is a custom image-based CAPTCHA service that lets site owners create their own image selection challenges. Unlike traditional CAPTCHAs that use pre-built datasets, you upload your own images and define what's correct — giving you full control over the challenge content.

## How it works

Implementing yCAPTCHA involves two essential components that work together:

1. **Client-side**: [Embed the widget](/docs/get-started/embed-widget) — Add the yCAPTCHA iframe to your webpage. Users solve an image selection puzzle and a verification token is generated.
2. **Server-side**: [Validate the token](/docs/get-started/server-validation) — Verify the token on your server using the Siteverify API to ensure it is authentic and has not been tampered with.

| Component  | Description                                                         |
| ---------- | ------------------------------------------------------------------- |
| Site Key   | Public key (`pk_...`) used to load the widget on your page.         |
| Secret Key | Private key (`sk_...`) used for server-side token validation only.  |
| Puzzle     | An image challenge you configure in the dashboard.                  |

## Security requirements

- **Server-side validation is mandatory.** Never trust the client alone. You must call the [Siteverify API](/docs/api-reference/siteverify) to confirm every token.
- **Tokens are single-use.** Once verified, the token is permanently deleted and cannot be reused.
- **Tokens expire after 5 minutes.** Expired tokens are rejected by the Siteverify API.
- **Protect your Secret Key.** Never expose `sk_...` in client-side code.
