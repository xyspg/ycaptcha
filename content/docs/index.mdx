## Introduction

yCAPTCHA <span className="text-sm text-neutral-700 dark:text-neutral-400">(your-CAPTCHA)</span> is a custom image-based CAPTCHA service that lets site owners create their own image selection challenges. Unlike traditional CAPTCHAs that use pre-built datasets, you upload your own images and define what's correct — giving you full control over the challenge content.

## Getting your API Key

Create a site and get API key in [Dashboard](https://ycaptcha.xyspg.moe/dashboard).

<Callout title="Security" type="warn">
  Never expose your Secret Key (`sk_...`) in client-side code.
</Callout>

## Embed in 2 lines

```html
<div class="y-captcha" data-sitekey="YOUR_SITE_KEY"></div>
<script src="https://ycaptcha.xyspg.moe/captcha.js" async defer></script>
```
