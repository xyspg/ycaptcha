## Overview

yCAPTCHA (your-CAPTCHA) is a CAPTCHA widget for small communities and subcultures. Site owners upload their own images and build challenges around shared in-jokes, like subway lines, rhythm game charts, dev tools, niche memes, instead of boring traffic lights.
